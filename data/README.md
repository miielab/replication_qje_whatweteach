The data that needs to be downloaded into this folder can be found here.

Below we list each data file in this folder and describe the relevant variables
## `book_purchase_data.Rdata`
This file contains one dataset called `collection_event_time` which contains information on the average number of children's books purchased on a given number of days before or after in a given category of children's books
  - `collection_citation`: The collection (e.g. Mainstream or Diversity) and the citation (e.g. Award Winners or Award Honors)
